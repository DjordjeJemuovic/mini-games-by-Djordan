# Igra vesanja

Browser verzija ostaje JavaScript igra u `index.html`. Samostalna Python desktop verzija koristi Pygame.

## Pokretanje Python verzije

Pokreni `Start-Vesanje.bat` ili `main.py`. Potreban je Python 3 sa Pygame-om.

## Pravila i kontrole

Prvi igrac unosi imena, zagonetku i tajnu rec. Posle predaje ekrana drugi igrac pogadja slova latinice koristeci klik na ekran ili tastaturu. Na raspolaganju je sest gresaka. Rezultat ostaje sacuvan kroz vise rundi dok je prozor otvoren.

- Tab menja polje u pocetnom unosu.
- Enter potvrduje unos.
- Escape zatvara igru.
- Dugme **Izlaz** zatvara igru mišem.
