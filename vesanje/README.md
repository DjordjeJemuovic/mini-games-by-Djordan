# Igra vešanja

Igra vešanja je dostupna iz glavnog menija Mini Games-a kao browser igra, a može da se pokrene i kao samostalna Python aplikacija.

## Browser verzija

U glavnom meniju izaberi **Vešanje**. Igrači i boje se prenose iz početnog ekrana.

## Samostalna Python verzija

Pokreni `Start-Vesanje.bat`, izaberi Python vešanje u desktop pokretaču ili pokreni `main.py` direktno. Potreban je Python 3 sa Tkinter podrškom.

Prvi igrač unosi zagonetku i tajnu reč. Posle predaje ekrana, drugi igrač pogađa slova latinice. Ima šest grešaka; svaka greška iscrta sledeći deo figure. Rezultat se vodi kroz više rundi.
